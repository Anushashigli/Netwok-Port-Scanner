 Netwok-Port-Scanner
📌 Overview
This project is a simple yet effective Python-based network port scanner designed for cybersecurity learning and basic vulnerability assessment. It helps users identify open, closed, and filtered ports on target systems, providing visibility into potential security risks.
🚀 Features
- Scan single IP addresses or ranges
- Detect open, closed, and filtered ports
- Identify common services running on open ports
- Lightweight and easy to use (built with Python socket and threading)
- Generates clear, structured reports (text/CSV)
🎯 Purpose
The tool is intended for educational and defensive use only. It helps students, researchers, and small organizations understand network exposure and improve their security posture by identifying vulnerable ports before attackers can exploit them.
⚙️ Tech Stack
- Language: Python
- Libraries: socket, threading, argparse (optional: nmap integration)
